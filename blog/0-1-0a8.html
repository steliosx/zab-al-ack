A real Zabbix delivery exposed a webhook bug

2026-09-11 · candidate 0.1.0a8

Ackline release history. The project is now Zab-al-ack; this post retains the names and results recorded for this candidate.

The a8 release-preparation report records the first native and deployment-service execution of the work added in a6 and a7: 36 PostgreSQL 18.3/PgBouncer cases, five real Zabbix 7.0.10 cases, and four deployment-service cases with thirteen required observations. Those runs used disposable source-built services. The Docker forms of the labs were not run.

A missing cause was not a numeric ID

The first webhook delivery failed with Invalid numeric identifier: cause. In the Zabbix 7.0.10 lab, {EVENT.CAUSE.ID} expanded to *UNKNOWN* for a problem without a cause event. The reference media type had rejected that value since a1, and the synthetic test had asserted the rejection. Those cause-less problem notifications could not reach Alerta. The a8 fix treats this exact value as an absent cause and keeps other identifier validation intact.

The behavior is supported by the inspected upstream 7.0.10 source. It is recorded as amendment A3. Three lab faults were also corrected: a test left verification leases live, imported scripts used CRLF line endings, and a newly configured action needed time to reach the server's configuration cache.

What the independent review added

The original a8 wheel, sdist and source archive rebuilt byte-for-byte. The independent reference run passed 725 tests, skipped 22 and failed none. It also found that the export gate and unsigned archive verifier could accept a deployment report labelled PASS even when its counts, observations or cleanup contradicted that label.

A proposed tooling correction adds a shared evidence validator and 56 regression cases. The corrected checkout passed 781 reference tests, skipped 22 and failed none; all 20 curated nightly mutations were detected. Runtime Python, SQL and the media artifacts are unchanged by that correction. The review branch remains version a8 and is not a new published release.

Native PostgreSQL/PgBouncer, real Zabbix and the deployment-service lab were not rerun in the independent review. The original service reports remain separate. In particular, the supplied local deployment report used an editable source installation, and its local bootstrap was not included. A fresh wheel installation smoke test passed, but the complete installed-wheel service path still needs a reproducible run.

Next steps are to run the packaged service path on a supported isolated host, complete the webhook transport remediation, and exercise the hosted checks. Production gates and publication-owner inputs remain open. See tests and evidence for the current scope.

Details for this candidate are in the cumulative changelog and the release amendments shipped with the source. Nothing on this page is a production or publication claim.
