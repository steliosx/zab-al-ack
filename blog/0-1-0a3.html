One name everywhere

2026-09-10 · candidate 0.1.0a3

Ackline release history. The project is now Zab-al-ack; this post retains the names and results recorded for this candidate.

Until now the package, the schema, the roles and the signed marker carried three different names from the project's history. That is how you end up with a security review that talks about a role nobody can find. 0.1.0a3 is ackline end to end: module, CLI, schema, roles, trigger, marker prefix, comment prefix, metrics, paths.

A rename is a mechanical change with a thousand places to go wrong, so we did it as an ordered substitution applied to the reviewed a2 code and compared the result byte for byte. Source and SQL matched. The one exception we found later, the SQL manifest digests, was caught by the next review.

Then we built Zabbix 7.0.10 from source, put a PHP frontend in front of it, and ran the API contract for real: exact event read, approved hosts, a restricted token that cannot see an outside event, and one explicit acknowledgement with a read-back. Four cases, four passes, on a disposable instance with no media types and no actions.

We also found that the export audit was happily selecting lab database files into the public tree on a machine that had run the lab. Fixed, with a regression test.

Details for this candidate are in the cumulative changelog and the release amendments shipped with the source. Nothing on this page is a production or publication claim.
