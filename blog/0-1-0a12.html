An acknowledgement, seen from Zabbix

2026-09-12 · candidate 0.1.0a12

Follow an acknowledgement from the operator’s action in Alerta to the original problem in Zabbix. This a12 lab capture shows the source event after delivery, a separate human update and recovery.

Read the Actions column from the bottom. The source action sent the reference source fact to the lab’s Alerta. Two seconds later the worker acknowledged the problem with the neutral [zabalack] comment. The update fact for that comment went out and was filtered as an echo on the other side. An operator added a human update, which was delivered and recorded. The recovery fact closed it. The image shows the source side of that sequence. The accompanying run record separately reports thirteen checks across four deployment tests.

A later independent review on Zabbix 7.0.30 found and corrected the lab role-provisioning issue. Its results are separate from the supplied capture and preparation records below.

What else ran

The supplied a12 preparation records forty-two native PostgreSQL 18.3 and PgBouncer cases in five fresh clusters, five real Zabbix 7.0.10 cases, and the deployment lab’s four cases from the installed wheel. The earlier run on unmodified a11 had forty-one native cases. The a11 walkthrough test now runs natively as well, not only under WASM. Nothing failed; a12 changes no runtime code.

The three transcript pages were also rendered in headless Chromium and shipped as PNGs beside the SVGs, with the browser version and hashes recorded.

What it still is not

Lab data on a disposable instance, not a production Zabbix. No Alerta UI screenshot — the Alerta Web UI is a separate project the lab does not install. The Docker Compose forms, hosted CI, signed attestation, A2 and the eight deployment gates remain open, same as before.

See the illustrated workflow for all four views.

Zab-al-ack is independent of Alerta and Zabbix. Public package and repository ownership are still being prepared. The website is informational and does not connect to monitoring systems.
